# Data

- `psychologymap-data.js`: the canonical dataset, assigned to `window.PSYMAP`. It holds threads, roots, nodes (school / theory / person / concept / work / application), edges, questions, debates and myths. Chinese text is the source; the schema is in `../docs/V2_FRAMEWORK.md` §3 and `../docs/V2_1_SPEC.md` §1.
- `en/*.json`: the English overlay, `{ "<id>": { "<fieldPath>": "English text" } }`. Use `node data/en-tool.mjs dump <group>` to see what needs translating and `node data/en-tool.mjs check` to verify coverage.
- `book-links.json`: generated by `tools/match-books.mjs`. It holds the chosen Douban edition (with alternates), the Open Library work, and the ids judged to be the same work. Entries reviewed by hand carry `enChecked`.
- `covers.json`: generated by `tools/fetch-covers.mjs`. It maps each work id to its cover file in `../covers/`.
- `validate.js`: run `node data/validate.js` after any data edit.
- `verification-log.md`: the fact-check record.
- `psychologymap-skeleton.js`: the original skeleton the dataset was built from, kept for reference.
- `cache/`: pipeline cache, git-ignored.

The build (`../build.js`) inlines the dataset and the overlays into `../index.html`.
