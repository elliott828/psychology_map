# Project scope

## Purpose

`psychology_map` is a public-facing visual guide to the history and structure of modern psychology. It is designed to help learners understand when systems appeared, how they relate, which people shaped them, and where to begin reading.

It is an orientation map, not a diagnostic instrument, clinical decision system, bibliometric database, or claim of a final historical canon.

## Primary audience

- General readers beginning to study psychology.
- Students who need a navigable overview before entering specialist literature.
- Readers comparing schools, historical figures, theoretical relationships, and reading paths.

Readable labels and interaction targets therefore take priority over dense academic notation. The main overview should remain usable on an ordinary laptop screen.

## Product boundaries

- Time controls horizontal ordering in chronology views.
- Lineage controls the four-domain color code.
- Literature contribution controls column height and people-node size provisionally.
- Structural breadth controls column width within a deliberately narrow range.
- A selected relationship network remains locked while the user pans or zooms.
- The mountain image is atmospheric background and must not become the visual subject.

## Languages

The supported interface languages are Simplified Chinese, English, and Japanese. Proper names should be explicitly checked in all three languages rather than generated by truncating a Chinese-first label.

## Repository convention

- `index.html` is the current application.
- `docs/` records decisions, model definitions, and unresolved questions.
- `archive/` stores historical prototypes and should not silently replace current behavior.
- Changes to contribution rankings must document the formula, evidence source, and version.
