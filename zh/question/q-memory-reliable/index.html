记忆可靠吗

问题·Can Memory Be Trusted?

几条脉络各自的解释

  • 重构记忆 意识与认知回忆是重新建构，不是取出录像，所以每次回忆都可能改写。
  • 错误信息效应 意识与认知事后听到的暗示性信息可以悄悄改变记忆，并且人对改变后的记忆同样自信。
  • 多重记忆系统 脑与生物事实、技能、情绪记忆依赖不同的系统，失忆者仍能学会新技能。
  • 压抑与“被压抑的记忆” 无意识与深度“被压抑的记忆可原样恢复”缺少证据，但人确实可以有意识地回避回忆。
  • 延长暴露疗法 临床与心理健康在创伤治疗中，重新讲述会改变记忆的情绪重量，而不是替换事实。
