多重记忆系统

理论·1980·Multiple Memory Systems

记忆不止一种：能说出来的事实与事件记忆依赖海马，而骑车、打字这类技能记忆依赖别的脑区，所以失忆的人仍能学会新技能。

历史影响 ●●●●○·证据状况：证据较强·大众知名度 ●●○○○

所属学派
神经心理学
标志性事件
科恩与斯奎尔发表陈述性记忆与程序性记忆的区分
证据怎么说
失忆病人保留技能学习却丧失事件记忆，这类分离证据丰富；系统的具体划分仍在讨论。
