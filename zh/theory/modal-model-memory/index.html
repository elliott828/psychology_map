多重存储记忆模型

理论·1968·Modal Model of Memory

信息先进入极短暂的感觉记忆，经注意进入有限的短时记忆，经复述才进入长时记忆。

历史影响 ●●●●○·证据状况：有支持但有边界·大众知名度 ●●●○○

所属学派
认知心理学
标志性事件
阿特金森与希夫林提出感觉记忆—短时记忆—长时记忆模型
证据怎么说
作为教学框架影响极大，但“串联存储”的结构已被更灵活的模型取代。

代表人物

  • 理查德·阿特金森 1929–
  • 理查德·希夫林 1942–
