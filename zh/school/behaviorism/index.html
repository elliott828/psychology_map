行为主义

学派·1913·Behaviorism

心理学应当像物理学一样研究可观察、可测量的行为，把内省与“意识”排除在科学之外，并把行为解释为环境刺激的结果。

历史影响 ●●●●●·证据状况：历史意义为主·大众知名度 ●●●●○

脉络
学习与行为
标志性事件
华生发表《行为主义者眼中的心理学》，主张心理学只研究可观察的行为
证据怎么说
学习规律经受住了检验，但“只研究行为、不谈心理”的纲领已被认知研究取代。
关键人物
约翰·华生

核心理论

  • 彻底行为主义 1945内部的想法与感受也算行为，只是看不见；解释行为只需找出环境中的前因与后果，不必假设心中的“实体”。

代表人物

  • 约翰·华生 1878–1958
  • B. F. 斯金纳 1904–1990

关键概念

  • 刺激—反应行为主义用来描述行为的基本单位：外部刺激引发可观察的反应。

与其他学派的关系

  • ← 发展 效果律桑代克的动物实验方法是行为主义的先声
  • ← 发展 经典条件作用华生以条件反射作为解释一切学习的基本单位
  • → 发展 操作性条件作用斯金纳把行为主义推向彻底，只分析行为与后果
  • → 分支 新行为主义保留客观方法，却加入目的与期望等内部变量
  • ← 批评 味觉厌恶与生物准备性味觉厌恶显示学习有生物性偏好，刺激并不等价
  • ← 批评 接触安慰幼猴不为奶而依附，驳斥“依恋来自喂食强化”
  • ← 批评 过度理由效应奖励并不总是增强行为，也会削弱原本的兴趣
  • ← 反动 实验心理学反对内省法，主张只研究可观察的行为
  • ← 发展 机能主义关注适应与功能，为客观地研究行为铺了路
  • → 反动 认知革命语言与思维无法只用刺激与反应解释
  • → 反动 需求层次与自我实现人本主义自称“第三势力”，反对行为主义的机械观
