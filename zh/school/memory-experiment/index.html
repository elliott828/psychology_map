记忆的实验研究

学派·1885·Experimental Study of Memory

把高级心理过程也放进实验室：用自己做被试，测量学习一串无意义音节后遗忘得多快。

历史影响 ●●●○○·证据状况：证据较强·大众知名度 ●●●○○

脉络
意识与认知
标志性事件
艾宾浩斯《论记忆》：用无意义音节测量遗忘曲线
证据怎么说
遗忘曲线与间隔效应在百年后的重复实验中依然成立。
关键人物
赫尔曼·艾宾浩斯

核心理论

  • 遗忘曲线 1885学过的内容在最初的几小时到几天内忘得最快，之后越来越慢；分散的重复复习能让曲线变得平缓。

代表人物

  • 赫尔曼·艾宾浩斯 1850–1909

关键概念

  • 提取练习（测试效应）自己试着回忆，比反复阅读学得牢。
