图式与记忆重构

学派·1932·Schema and Reconstructive Memory

记忆不是把过去的录像取出来，而是用已有的知识框架（图式）在回忆时重新拼出来，所以会有扭曲。

历史影响 ●●●○○·证据状况：有支持但有边界·大众知名度 ●●○○○

标志性事件
巴特利特《记忆》：人们回忆陌生故事时会按自己的文化图式改写它
证据怎么说
记忆受已有知识影响的大方向稳固；他的原始实验比教科书所说的混乱。

核心理论

  • 重构记忆 1932回忆的时候，人会把残缺的片段用已有知识补全，并常常自然地改成符合自己预期的样子。
  • 错误信息效应 1974事后接触到的暗示性信息，会悄悄改变人对原事件的记忆，人还会对改变后的记忆很有把握。
  • 记忆的七宗罪 1999遗忘、分心、阻塞、张冠李戴、暗示、偏差、挥之不去——七类记忆错误，其中不少是正常记忆的副作用。
