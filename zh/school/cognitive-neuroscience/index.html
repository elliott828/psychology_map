认知神经科学

学派·1979·Cognitive Neuroscience

把认知心理学的任务设计与脑损伤、脑成像、电生理方法结合，追问思维、记忆、注意在脑中如何实现。

历史影响 ●●●●○·证据状况：有支持但有边界·大众知名度 ●●○○○

脉络
脑与生物
标志性事件
加扎尼加与认知心理学家乔治·米勒在 1970 年代末合作命名这一学科
证据怎么说
脑成像发现了稳定的功能网络，但小样本、统计阈值与“逆向推理”问题让不少个别结论难以重复。
关键人物
迈克尔·加扎尼加

核心理论

  • 意识的神经相关物 1990不直接问意识是什么，而是找出“人报告看到了”与“没看到”时，脑活动有什么不同。

代表人物

  • 弗朗西斯·克里克 1916–2004
  • 乔治·米勒 1920–2012
  • 迈克尔·加扎尼加 1939–
  • 克里斯托夫·科赫 1956–

关键概念

  • “结合问题”颜色、形状、运动分开处理，我们为何看到统一的物体。

与其他学派的关系

  • ← 汇流 裂脑研究加扎尼加把裂脑方法带入这门新学科
  • → 发展 情感神经科学把损伤与成像方法用于情绪与决策问题
  • ← 汇流 认知革命提供了可在脑中检验的认知模型
  • ← 汇流 神经心理学提供了脑损伤病例与成像的方法
  • → 汇流 维度化模型（RDoC／HiTOP）RDoC 用神经环路组织研究，来自认知神经科学
  • → 发展 人脑连接组从单个脑区转向全脑连接
  • → 发展 青少年脑认知发展队列把脑成像放进大规模追踪研究
  • → 桥接 神经精神分析用脑损伤与成像研究检验精神分析的概念
