工作记忆

概念·Working Memory

同时“保持并加工”几件事的有限容量。

所属学派
认知心理学
通俗地说
大脑暂时保存并操作信息的空间，比如心算时把中间结果记在脑里。容量很小，且因人而异、会被压力占用。
例子
边打电话边记下地址，或者心算 47×6 时先算 40×6 再记着加 42。
常见误用
常被说成“记忆力”的同义词，实际上它与长期记忆是不同的系统；也不能靠几个小游戏明显提高。
