Alan Baddeley

Person·1934–·艾伦·巴德利

British psychologist who proposed the model of working memory

Lived
1934–
Schools
Cognitive Psychology

Theories

  • Working Memory Model 1974Short-term memory is not a box. It is a workbench where information is stored and processed at the same time. Verbal and visuospatial information are handled separately, and a central executive coordinates them.
