Temporal-Difference Learning

Theory·1988·时序差分学习

An algorithm in which an agent learns while acting. It corrects its estimate of each state's value using the difference between its current estimate and a later estimate.

Historical influence ●●●●○·Evidence: Strong evidence·Public familiarity ●○○○○

School
Computational Reinforcement Learning
Landmark
Sutton, 'Learning to Predict by the Methods of Temporal Differences' (1988).
What the evidence says
The algorithm has been validated extensively in artificial intelligence. Schultz's neural data showed a form of dopamine activity that matches it.
