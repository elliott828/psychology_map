Modal Model of Memory

Theory·1968·多重存储记忆模型

Information first enters a very brief sensory memory. Attention moves some of it into a limited short-term memory, and rehearsal moves it into long-term memory.

Historical influence ●●●●○·Evidence: Supported, with limits·Public familiarity ●●●○○

School
Cognitive Psychology
Landmark
Atkinson and Shiffrin proposed the sensory memory, short-term memory, and long-term memory model.
What the evidence says
It has been highly influential as a teaching framework. But its strictly sequential storage structure has been replaced by more flexible models.

Key people

  • Richard Shiffrin 1942–
