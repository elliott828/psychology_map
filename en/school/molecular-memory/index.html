Molecular Basis of Memory

School·1970·记忆的分子机制

Breaks 'learning' down to the level of cells: simple learning changes chemical signals at synapses and protein synthesis, and long-term memory requires new proteins.

Historical influence ●●●○○·Evidence: Strong evidence·Public familiarity ●○○○○

Thread
Brain and Biology
Landmark
Kandel and colleagues study habituation and sensitization using the gill-withdrawal reflex of the sea slug Aplysia
What the evidence says
Cellular mechanisms, from protein synthesis in single neurons to memory consolidation, have been confirmed across several species.
Key figure
Eric Kandel

Core theories

  • Aplysia Sensitization and Synaptic Memory 1982After sea slugs (Aplysia) are repeatedly given electric shocks, their sensory neurons release more neurotransmitter. Long-term memory also requires the synthesis of new proteins to consolidate synaptic changes.

Key people

Key concepts

  • Memory ConsolidationNew memories take time to move from fragile to stable.
