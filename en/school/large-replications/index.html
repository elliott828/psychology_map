Large-Scale Replication Projects

School·2015·大规模重复研究

Many labs use the same protocol and large samples to each replicate the same famous result, turning 'can it be replicated?' into a question that can be answered statistically.

Evidence: Strong evidence·Public familiarity ●●○○○

Thread
Individual Differences and Measurement
Landmark
The Open Science Collaboration replicates 100 psychology studies
What the evidence says
A series of multi-lab collaborations shows that replication success rates and effect sizes are generally lower than in the original studies. These conclusions have themselves been repeatedly confirmed.
Key figure
Brian Nosek

Core theories

  • Many Labs Replication Project 2014Dozens of labs run the same protocol and each repeat the same set of classic experiments. The results are then pooled. Some effects reappear reliably, while others nearly vanish.
