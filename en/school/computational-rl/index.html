Computational Reinforcement Learning

School·2015·计算强化学习

Describes learning as an algorithm in which an agent tries things in an environment and maximizes cumulative reward, so that psychological learning theory and artificial intelligence share the same mathematics.

Evidence: Little research·Public familiarity ●●○○○

Thread
Learning and Behavior
Landmark
Deep reinforcement learning is published in Nature, using one algorithm to learn to play Atari games
What the evidence says
As a method in artificial intelligence it has been very successful. As a theory of human learning, its fit with behavioral data is still being tested.
Key figure
Richard S. Sutton

Core theories

  • Temporal-Difference Learning 1988An algorithm in which an agent learns while acting. It corrects its estimate of each state's value using the difference between its current estimate and a later estimate.
