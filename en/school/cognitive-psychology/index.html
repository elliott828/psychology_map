Cognitive Psychology

School·1967·认知心理学

An experimental discipline that studies how perception, attention, memory, language and thinking work. It has become the backbone of modern psychology.

Historical influence ●●●●○·Evidence: Strong evidence·Public familiarity ●●●○○

Thread
Mind and Cognition
Landmark
Neisser's Cognitive Psychology summarizes this new field and names it
What the evidence says
Core findings on attention, working memory and language comprehension are mostly replicable; some models, such as overly strict serial processing, have been revised.
Key figure
Ulric Neisser

Core theories

  • Modal Model of Memory 1968Information first enters a very brief sensory memory. Attention moves some of it into a limited short-term memory, and rehearsal moves it into long-term memory.
  • Working Memory Model 1974Short-term memory is not a box. It is a workbench where information is stored and processed at the same time. Verbal and visuospatial information are handled separately, and a central executive coordinates them.
  • How People Learn Framework 1999Learners enter the classroom with existing ideas. To understand, they need to build conceptual frameworks on top of facts and learn to monitor their own learning.

Key concepts

  • Working MemoryA limited capacity to hold and work with several things at once.
  • Inattentional BlindnessFocusing on one thing can make you miss other obvious things.
  • Confirmation BiasA tendency to look for evidence that supports what we already think.
  • PrimingEncountering one stimulus shapes how related content is processed afterward.

Relations to other schools

  • ← Bridges Schema and Reconstructive Memory'Schema' became a basic term in cognitive psychology.
  • ← Bridges FunctionalismBoth ask what the mind does rather than what elements it is made of.
  • ← Develops Cognitive RevolutionNeisser organized the new paradigm into a discipline and named it.
  • → Develops Heuristics and BiasesApplies research on cognitive processing to judgment and decision-making.
  • → Reacts ConnectionismConnectionism disagrees that the mind is serial rule-based symbol manipulation.
  • → Reacts Embodied CognitionEmbodied views reject the mind as symbol processing detached from the body.
  • ← Bridges Gestalt PsychologyResearch on holistic perception and problem solving was absorbed into cognitive psychology.
  • ← Bridges Social Learning TheoryObservational learning brings attention and memory into learning theory.
  • ← Critiques Cultural PsychologyMany 'universal' cognitive conclusions hold only in Western samples.
