Experimental Study of Memory

School·1885·记忆的实验研究

Brings even higher mental processes into the lab: using himself as the subject, Ebbinghaus measured how fast he forgot after learning a list of nonsense syllables.

Historical influence ●●●○○·Evidence: Strong evidence·Public familiarity ●●●○○

Thread
Mind and Cognition
Landmark
Ebbinghaus's On Memory uses nonsense syllables to measure the forgetting curve
What the evidence says
The forgetting curve and the spacing effect still hold up in replications a century later.
Key figure
Hermann Ebbinghaus

Core theories

  • Forgetting Curve 1885Material learned is forgotten fastest in the first few hours to days, then more slowly. Spaced repetition flattens the curve.

Key people

  • Hermann Ebbinghaus 1850–1909

Key concepts

  • Retrieval PracticeTrying to recall something on your own helps you learn it better than rereading.
