Object Permanence

Concept·客体永存

Knowing that a hidden object still exists.

School
Cognitive Development Theory
In plain words
Understanding that objects continue to exist even when we cannot see them. Piaget thought this emerged around eight months, while later experiments suggest it appears earlier.
Example
In peekaboo, a very young baby seems to think Mom has “vanished.” An older child will look for her.
Common misuse
The claim that “babies only get this at a few months old” depends on how it is measured. It is not a fixed age.
