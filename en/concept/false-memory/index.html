False Memory

Concept·虚假记忆

People can vividly “remember” things that never happened.

School
Schema and Reconstructive Memory
In plain words
Through suggestion, imagination and repeated retelling, people can form vivid memories of events that did not happen. Subjectively, these are indistinguishable from real memories.
Example
In one experiment, some participants were told that they had got lost in a shopping mall as children. Afterward, they went on to describe details of the event.
Common misuse
Often misread as “all memories of trauma are unreliable.” The real finding is narrower: how vivid a memory feels is not the same as how accurate it is.

Related myths

  • “Memory is like a video recorder. If you think hard enough, you can retrieve it exactly as it was” False
