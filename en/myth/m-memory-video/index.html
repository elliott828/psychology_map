“Memory is like a video recorder. If you think hard enough, you can retrieve it exactly as it was”

Misreading·记忆像录像机，只要想得足够深入就能原样取出。

Verdict：False

Memory is rebuilt each time it is recalled, and it is influenced by existing knowledge, suggestion and current emotion. Vivid, confident memories can still be wrong. For example, people's “flashbulb memories” of where they were on 9/11 often change in details over time.
