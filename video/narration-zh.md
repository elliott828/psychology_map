# 讲解视频配音稿

共 11 段、55 句。每段录成一个音频文件，文件名用段落编号，例如 `01.m4a`、`02.m4a`……手机录音、m4a / mp3 / wav 都可以。

**录音要求**
- 句与句之间停顿 **1.5 秒左右**。我会按停顿把每段切成单句，再对齐到画面。
- 一句念错了就停 3 秒，从这一句重新念；我会保留后一遍。
- 语速自然即可，不用刻意放慢。画面会跟着你的节奏调整。
- 找安静的房间，手机离嘴一拳左右，不要对着麦克风吹气。

## 01 · 开场：这个网站为什么存在

1. 这是 Psychologymap，一张心理学思想地图。　<sub>（“Psychologymap”读作 Psychology map）</sub>
2. 做它的初衷是：心理学不是某一位大师的学说，
3. 而是一百多年里，许多条线索同时生长出来的领域。
4. 所以这张地图保持中立，不从任何一个学派出发。
5. 它想让你看见：一个理论从哪里来，和谁对话，又走向了哪里。
6. 下面我们一边操作，一边看怎么用它。

## 02 · 时间沙漏

1. 首页是一个时间沙漏，从上往下读。
2. 上半部是源头：1879 年以前，两千多年的哲学、医学和修行传统。　<sub>（“1879”读作“一八七九”）</sub>
3. 它们在瓶颈处汇聚。这一年，心理学成为一门实验科学。
4. 下半部，九条脉络一路展开到今天；底部开口，表示它还在生长。
5. 按住鼠标左右拖动，可以旋转沙漏。
6. 点左侧的脉络名称，这条脉络会转到正面。
7. 鼠标停在节点上，会出现它的简介。
8. 圆点越大，代表它在大众中越有名。
9. 滚动鼠标滚轮可以放大沙漏，看清密集处的名字；在手机上，用双指缩放。

## 03 · 群山

1. 点左下角的「展开为地图」，沙漏会摊开成九列山脊。
2. 横轴是时间；山峰越高，说明那个年代登场的重要学派越多。
3. 鼠标经过山脊上的圆点，就能看到这个学派的简介。
4. 上方的「标注」，可以在学派、人物和著作之间切换。
5. 想知道高度怎么来的，点「高度怎么算？」就有说明。

## 04 · 节点详情

1. 点任意一个圆点，右侧会打开它的详情。以荣格的分析心理学为例。
2. 最上面是它的要点，以及代表人物和代表作。
3. 「评分」告诉你它的历史影响、证据状况，和在大众中的知名度。
4. 同时，地图上会亮起它和其他学派的关系线：从哪里分出，又启发了谁。
5. 详情里的每个名字都可以点击，顺着关系一路走下去。

## 05 · 单条脉络

1. 想细看一条脉络，就点左侧的脉络名称。
2. 这里把这条脉络的学派按时间排开，下方列出它们的关键理论、提出者和年份。
3. 曲线下方的连线，标出学派之间的继承、分支和反对。
4. 顶部的色块，可以切换到其他脉络。

## 06 · 结构

1. 顶部导航的「结构」，回答另一个问题：今天的心理学由哪些部分组成。
2. 一百多个学派各占一格：纵向是它在哪个层次解释人，横向是它主要在做什么。
3. 鼠标停在一个学派上，同一条脉络的其他学派会一起亮起。
4. 上方的筛选，可以只看证据较强的，或者某一类活动。

## 07 · 人物

1. 「人物」页是一条时间轴：每个人一条线，从出生到去世。
2. 线上的圆点，是他提出某个理论的年份。
3. 现代心理学之前的人物默认收在左侧，需要时可以展开。
4. 排序可以按年代或按影响，也可以只看某一条脉络。
5. 点任何一个人，就能看到他的理论和著作。

## 08 · 问题

1. 如果你带着一个生活里的困惑而来，可以从「问题」开始。
2. 比如「拖延」：几条脉络各自给出解释，并标出证据有多强。
3. 点卡片里的概念，就能跳到它的详情，看它的来历。
4. 旁边还有学界的「争论」，和流传很广的「误读」。

## 09 · 搜索

1. 知道自己要找什么，就用右上角的搜索框，或者直接按斜杠键。
2. 学派、理论、人物、书和问题都能搜，中文、英文都可以。
3. 比如输入「依恋」，或者「Bowlby」。　<sub>（“Bowlby”按英文读）</sub>
4. 选中一个结果，就会直接打开它。

## 10 · 阅读

1. 最后是「阅读」。在「阅读路径」里，输入一个理论或学派。
2. 阅读路径分成三列：先读、这个学派本身，和接着读。
3. 先读，是理解它之前需要的；接着读，是它启发出来的方向。
4. 每本书都给出豆瓣上评分最高的中文版，和推荐的英文版，点击就能打开。
5. 这样，你不只知道一个名字，还知道该从哪本书开始。

## 11 · 结尾

1. 右上角可以随时切换中文和英文。
2. 最简单的用法，只有三步：
3. 从一个你关心的问题开始，找到解释它的理论，再沿着阅读路径读下去。
4. 祝你在这张地图上，找到自己的路。
